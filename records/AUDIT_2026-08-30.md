# Full-paper audit, 30 August 2026

Findings from a line-by-line audit of the manuscript against the data. Recorded whether or not they
are convenient.

## A. Figures were computed from a superseded data panel  — FIXED

Figures 1, 2 and 3 were generated from `panel.npz` (1,255 sessions) while every table and test used
`panel2.npz` (1,340 sessions), the panel the paper describes. The figure values were pasted constants,
so nothing in the workflow could notice. `panel.npz` reproduces the manuscript's Hurst scalars exactly
(b = 0.9448, H = 0.4724, c = 0.00759), which is how the provenance was established.

All three figures are now regenerated from `panel2.npz` with every point computed in the cell that
draws it. Consequent text corrections:

| quantity | was | is |
|---|---|---|
| ⟨TMV⟩ crossing | θ ≈ 0.7% | **θ ≈ 0.50%** |
| Hurst noise floor | 0.0076 pt², 0.062/side | **0.0123 pt², 0.078/side** |
| Hurst b, H | 0.945, 0.472 | **0.950, 0.475** |
| local H | "flat at 0.47, no crossing" | **0.43–0.53 about 0.48, no monotone drift** |
| ⟨ω⟩/δ range, Introduction | 1.43 → 0.48, threefold | **1.34 → 0.49, 2.7-fold** |
| median leg duration, shortest θ | 20 seconds | **55 seconds** |
| ⟨ω⟩/δ by threshold | 2.07 → 0.79 | **1.59 → 0.80** |
| 0.45–0.65 band, four thresholds | 0.508 0.510 0.475 0.488, spread 0.035 | **0.504 0.517 0.465 0.483, spread 0.052** |

The 0.7% crossing contradicted the paper's own Section 3, which states the deficit is near zero at
θ = 5×10⁻³. The corrected 0.50% agrees with it.

## B. Vietnamese strings and truncated labels in Table 3  — FIXED

Configuration labels came straight from the grid-scan output and were still Vietnamese, truncated
mid-word to fit the column, which removed the exit rule from the blend rows. The running footer was
Vietnamese on all fourteen pages. Labels restored in full from `wfa.json`, rewritten compactly, and
the notation is now documented in the caption.

## C. The session was described as continuous  — FIXED

Section 2.1 said "continuous session from 09:15 to 14:45". The exchange has a midday break and the
sample contains zero observations between 11:30 and 13:00 — which the new Section 4 robustness test
depends on. The two statements contradicted each other.

## D. A label collision silently changed the walk-forward candidate set  — NOT FIXED, needs a decision

`s140_grid.py` builds thirty fade cells over θ ∈ {3e-3, 5e-3, 7e-3, 1e-2, 1.2e-2} and names them with

    f"{TH:.0e}|{window}|{exit}"

`f"{1.2e-2:.0e}"` and `f"{1e-2:.0e}"` are **both** `"1e-02"`. `s142_wfa2.py` then builds a dictionary
from those names, so the six θ = 1.2% cells overwrite the six θ = 1.0% cells:

    30 cells stored  →  24 in the candidate set  →  theta = 1.0% never enters it

Consequences, all verified against the stored grid:

1. Every fold of the reversal rule in Table 3 selected **θ = 1.2%** and is printed as `1e-02`, i.e.
   1.0%. Fold by fold the reported net (+117.35, +24.90, +277.80, +162.90, +60.65) matches the
   θ = 1.2% cell exactly and the θ = 1.0% cell not at all: for 2023 the 1.0% cell returns +280.75 on
   59 trades against the reported +117.35 on 25.
2. All five blend folds under the Calmar criterion also selected a cell carrying the ambiguous name.
3. Section 6 states a candidate set of "24 for the reversal rule". The count is right by coincidence;
   the composition is not the one described, and θ = 1.2% lies outside the six thresholds the rest of
   the paper uses.
4. The reported performance figures are correct **for the rule that actually ran**. They are attributed
   to the wrong threshold.

This also explains a discrepancy that surfaced independently: the reproduction notebook, whose fade
grid uses θ ≤ 1.0%, returns a stitched reversal walk-forward of net +850 at Sharpe 1.80, against the
manuscript's +644 at 1.50. Two different thresholds, not two different implementations — the notebook
and the original grid builder agree to the cent on any cell given the same θ.

**Options.** Relabel Table 3 to θ = 1.2% and disclose that 1.0% was excluded by the fault, leaving all
numbers unchanged; or re-run the walk-forward on the corrected grid, which changes the headline Sharpe,
net and Pardo efficiency. The second matches what the paper says it did. Author's decision.

## E. Reproduction notebook

`overshoot_deficit.ipynb` now computes everything from one `PANEL` constant, with no pasted results,

clean and all twenty-three agree. That cell exists because finding A was undetectable without it.
